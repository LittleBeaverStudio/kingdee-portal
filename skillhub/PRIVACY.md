## 🏠 一句话版

**这是一个装在你自己电脑上的本地工具。** 门户只监听 `127.0.0.1:8985`，不提供公网服务。
金蝶账号密码只存在于运行进程的内存里，看板数据由你自己的金蝶服务器提供。
**没有遥测、没有埋点、没有崩溃上报，我们不接收你的任何经营数据。**

## 📥 我们处理哪些数据

| 🧩 类别 | 📝 具体内容 | 📍 存放位置 | ⏳ 保留时间 | 📤 是否离开本机 |
|---|---|---|---|---|
| 🔑 登录凭据 | 金蝶账号、密码、服务器地址、账套 | 🧠 仅 Flask 进程内存 | 服务重启或退出登录即清空 | ❌ 否 |
| 🍪 会话令牌 | `sid` / `csrf` | 🪟 浏览器 `sessionStorage` | 关闭页面会话即失效 | ❌ 否 |
| 🏢 表单便利项 | 公司名、服务器地址、账套名、用户名 | 🪟 浏览器 `localStorage` | 直到清除站点数据 | ❌ 否（**从不保存密码**） |
| 🎨 界面偏好 | 主题（浅色/深色） | 🪟 浏览器 `localStorage` | 直到清除站点数据 | ❌ 否 |
| 💾 运行库 | `state.db`、`state.key`（本机配置、会话、发票云授权） | 🏠 `.portal-state-dsh/` 或 `~/.kingdee-portal/` | 直到你手动删除 | ❌ 否 |
| 📊 业务数据 | 费用、资金、销售、现金流等看板数值 | 🧠 进程内存 + 本机缓存 | 会话结束 / 缓存到期 | ✅ 仅来自并往返于**你自己的金蝶服务器** |
| 🧾 发票云授权 | 你主动填写的 client_id / secret | 🏠 本机、按公司隔离 | 直到你手动删除 | ⚠️ 仅调用你配置的发票云接口时 |

> ⚠️ **发票云是可选功能**。不配置就不产生相关请求；配置后，授权凭据仅用于调用
> `api.piaozone.com` 的接口，且不同公司的授权在同一台机器上互相隔离。

## 🌐 会连接哪些网络地址

| 🌍 目标 | 🎯 用途 | ⏱️ 何时发生 | 🔧 可关闭吗 |
|---|---|---|---|
| `127.0.0.1:8985` | 本机门户页面与 API（不经过外网） | 打开侧栏时 | 插件本身即此服务 |
| 你填写的金蝶服务器 | 登录、组织发现、看板取数 | 登录 / 刷新时 | 由你决定填哪个地址 |
| `api.piaozone.com` | 发票云上传与校验 | 仅在配置授权并主动使用报销办理时 | ✅ 不配置即不连 |
| `github.com` | 下载/更新插件代码 | 仅安装或升级时 | ✅ 装完即可不再访问 |

**默认不连**：❌ 分析统计服务 · ❌ 崩溃上报 · ❌ 广告 / 追踪像素 · ❌ 作者服务器 · ❌ 任何"云端账号体系"

> 🧬 代码中仍保留原公网版的遗留实现（含网络诊断、企业微信推送相关域名），
> 但 **DSH 本地模式已禁用对应接口**；详见 [SECURITY.md](SECURITY.md)。

## 🚫 明确不做的事

- ❌ **不收集**：不把账号、密码、公司名、单据、金额上传到我们或任何第三方。
- ❌ **不追踪**：没有埋点、没有设备指纹、没有使用时长统计。
- ❌ **不共享**：不向任何数据经纪商、广告平台或 AI 训练方提供数据。
- ❌ **不内置账号**：没有集成账号，所有请求使用登录者本人的金蝶会话。
- ❌ **不越权**：门户不做权限判断，能看到什么完全由你的金蝶权限决定。
- ❌ **不默认写入**：报销办理等写操作默认关闭（`enable_write_ops: false`）。

## 🔐 我们如何保护

| 🛡️ 措施 | 📖 说明 |
|---|---|
| 🧠 凭据内存化 | 账号密码不落盘；服务重启必须重新登录 |
| 🚪 会话隔离 | 后台任务结果按登录会话隔离，其他会话/匿名请求读不到 |
| 🧱 嵌入白名单 | 仅 DSH 桌面协议 + Host 提供的精确本机 Web 来源可 iframe 嵌入 |
| 🔒 地址校验 | 服务器地址默认要求 HTTPS，并拒绝私网地址 |
| 🧹 退出清理 | 退出登录移除该会话的后台任务，迟到结果不会写回 |
| 🗝️ 授权隔离 | 发票云配置按公司隔离，未配置的公司不会沿用上一家的凭据 |

⚠️ **已知边界**：桌面协议是「按协议放行」，不构成对同机不可信程序的隔离。
同一台机器上的其他程序若能访问 `127.0.0.1:8985`，仍可能打开门户页面。请在受信任的单机环境使用。

## 🧹 如何彻底删除我的数据

```bash
# 1️⃣ 停止本地服务（关闭 DSH 插件或结束 python scripts/serve_local.py 进程）

# 2️⃣ 删除本机运行库（按你实际使用的路径二选一）
rm -rf .portal-state-dsh/          # 由 DSH 插件启动时创建
rm -rf ~/.kingdee-portal/          # 独立运行时的默认位置

# 3️⃣ 清除浏览器站点数据：开发者工具 → Application → Storage → Clear site data
#    这将移除 sessionStorage 里的会话令牌与 localStorage 里的表单便利项

# 4️⃣ 如需移除插件
dsh plugin --profile desktop remove @local/kingdee-portal
```

删除运行库后，本机保存的发票云授权与配置一并消失，不会残留在云端。
